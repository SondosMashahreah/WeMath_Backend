# WE MATH Backend

FastAPI + SQLAlchemy + PostgreSQL. تسجيل فعلي بالـusername وكلمة المرور، صف محفوظ للطالب، أهل بحد خمسة أطفال، كتب وموارد دروس وحفظ التقدم.

## التشغيل والترحيل

فعّلي بيئة Python الحالية، ثم:

```bash
python -m pip install -r requirements.txt
```

احتفظي بإعدادات PostgreSQL الحالية في `.env`. ولدي مفتاح JWT خاصًا:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

انسخي الناتج إلى `JWT_SECRET_KEY` داخل `.env`. يُرفض الآن مفتاح المثال القديم المنشور بالمستودع ومفاتيح CHANGE_ME. هذا التغيير ينهي الجلسات السابقة دون حذف الحسابات.

خذي نسخة احتياطية من قاعدة البيانات المستخدمة قبل الترحيل:

```bash
python -m alembic current
python -m alembic upgrade head
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8100
```

الترحيل `wemath_family_20261025` يأتي بعد `wemath_catalog_20261019`. لا يحذف حسابات أو بيانات المنهاج. على قاعدة جديدة يشغّل Alembic السلسلة كاملة. لا تعيدي تشغيل install.sql أو seed.sql فوق فهرس مثبت. إذا ثُبّت الفهرس يدويًا خارج Alembic، تحققي من توافق سجل الترحيلات قبل استعمال stamp؛ لا تتجاوزي خطأ غير مفهوم أو تحذفي المخطط.

يُضاف الدوران student وparent تلقائيًا. `python -m scripts.seed_roles` متاح لإضافة باقي الأدوار.

## الحسابات القديمة

تأخذ اسم مستخدم `user_<id>` وتحتفظ بكلمة المرور. لمعرفة الأسماء من قاعدة بياناتك:

```sql
SELECT id, full_name, email, username FROM users ORDER BY id;
```

الطالب القديم الذي لا يملك صفًا يكمله مرة واحدة بعد الدخول. لا يُفترض له صف عشوائي. الدخول بالإيميل لم يعد مدعومًا؛ الحسابات الجديدة تختار username من البداية.

## الحساب والعائلة

username فريد بدون تمييز حالة الأحرف، من 3–32 حرفًا إنجليزيًا أو رقمًا أو `._-`. كلمة المرور 8–128 حرفًا وتُخزّن بتجزئة Argon2. الاسم والصف مطلوبان للطالب؛ الهوية والمدرسة والهاتف والإيميل والمديرية اختيارية. البريد غير الفارغ يظل فريدًا، والدخول باسم المستخدم.

الأهل ينشئون حساب الطفل أو يربطون حسابًا موجودًا ببيانات دخوله. الطفل مرتبط بولي أمر واحد. الحد خمسة أطفال يُفرض بأقفال المعاملات وبقيود SQL، وليس في الواجهة وحدها. يستطيع ولي الأمر تعديل صف وبيانات طفله وكلمة المرور وحالة الدخول، ومعاينة المنهاج بدون تسجيل تقدم. كل عمليات الطفل تتحقق من الملكية في الباك. تغيير الصف أو كلمة المرور أو حالة الدخول يلغي جلسات الطفل.

سجل التقدم واحد لكل طالب/درس. إعادة فتح درس مكتمل لا تلغي إنجازه. الإنجاز اختيار الطالب «أنهيت الدرس»، وليس نتيجة اختبار. قراءة الموارد وحفظ النشاط مقيدان بصف الطالب.

## محتوى الدروس

المنهاج الأصلي محفوظ في wemath_curriculum: 28 كتابًا، 126 وحدة، 587 درسًا. `semester=null` يبقى كتابًا كاملًا. مصادر الكتب لا تُنسخ محليًا وتظهر روابطها الخارجية في الواجهة.

ملف `app/data/lesson_resources.json` يفصل المحتوى الإضافي عن الخدمات. مثال، استبدلي القيم بمحتوى تراجعينه:

```json
{
  "g01t1-u01-l01": {
    "learn": {"demo": false, "text": "نص الدرس المعتمد"},
    "video": {"demo": false, "url": "https://your-domain.example/lesson.mp4", "text": "شرح الدرس"},
    "practice": {"demo": false, "text": "تدريب", "question": "كم ضلعًا للمربع؟", "choices": [3, 4, 5], "answer": 4}
  }
}
```

استبدلي رابط المثال بملف MP4/WebM فعلي عبر HTTPS؛ رابط صفحة YouTube ليس ملف فيديو مباشرًا. أعيدي تشغيل الباك بعد التعديل. الملف الافتراضي فارغ، ويستخدم محتوى تجريبيًا عامًا وحالة «لا يوجد فيديو» صريحة. لا تختلقي محتوى من المنهاج أو علامات للطلاب. ضعي demo=false فقط للمحتوى الذي راجعته.

## العقود والبنية

- `/api/auth/register`, `/api/auth/login`, `/api/auth/me`, `/api/auth/logout`: الحساب والجلسة.
- `PATCH /api/auth/me/profile`: استكمال صف الحساب القديم مرة واحدة.
- `GET/POST /api/parents/children`, `POST /api/parents/children/link`: إضافة الأطفال وربطهم.
- `PATCH /api/parents/children/{id}`, `PUT .../{id}/password`: بيانات الطفل وكلمة مروره.
- `GET .../{id}/progress`, `GET .../{id}/lessons/{lesson}`: المتابعة ومعاينة المنهاج.
- `GET /api/learning/lessons/{lesson}`, `PUT .../{lesson}/progress`, `GET /api/learning/progress`: موارد الدرس والنشاط.
- النشاط واحد من opened/book/learn/video/practice/game/completed. لا يرسل العميل student_id؛ يؤخذ من الجلسة.

الـAPI يعالج HTTP والأدوار، والخدمات حالات الاستخدام والمعاملات والملكية، والنماذج والترحيل قيود البيانات، ومستودع الموارد المحتوى الإضافي. لا تُرسل تجزئة كلمة المرور في الاستجابات.

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

الاختبارات المرفقة تستخدم SQLite مع المفاتيح الخارجية وتغطي الحسابات والحد والصلاحيات والتقدم وإبطال الجلسات. فحص الترحيل والتكامل الإضافي استخدم PostgreSQL المضمّن PGlite؛ ليس اختبار حمل أو تنافس معاملات على خادم PostgreSQL إنتاجي مستقل.
